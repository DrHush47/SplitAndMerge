# PPTX-Lab — Лаборатория тестирования и генерации презентаций

> **Цель стенда:**
> Практическая оценка, сравнительный аудит качества и выбор оптимального стека для создания и редактирования презентаций PowerPoint (`.pptx`) агентами.

---

## Архитектура тестирования («Баттл подходов»)

Стенд сравнивает три принципиально разных подхода на **едином тестовом сценарии** (бизнес-доклад из 3 слайдов: титульный с тезисом, слайд с ключевыми метриками/проблемой, сравнительная матрица решений):

| № | Подход | Стек | Особенности |
|---|---|---|---|
| **01** | **Baseline (Текущий)** | `python-pptx` | Базовая генерация по шаблонным блокам (текущая инструкция в `tech-executor.md`). |
| **02** | **Anthropic Gold Standard** | `PptxGenJS` (`anthropics/skills@pptx`) | Выверенная палитра (Midnight Executive / Coral), Hero-метрики (72pt), строгий запрет на цветные псевдо-разделители под заголовками, автоматический контроль отступов. |
| **03** | **MBB Consulting Style** | `hugohe3/ppt-master` | Стиль «Большой тройки» (McKinsey/BCG/Bain), Action Titles (заголовки-выводы), раздел-навигатор (Tracker), векторные матрицы сравнения данных. |

---

## Инструменты верификации и просмотра

- **PowerPoint COM Export:** нативный экспорт слайдов каждого `.pptx` в PNG (1920×1080) через локальный Microsoft PowerPoint 365.
- **Интерактивный просмотр:** локальная HTML-галерея для мгновенного визуального сравнения результатов слайд-в-слайд.
