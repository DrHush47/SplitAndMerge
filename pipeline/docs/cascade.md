# Каскад веб-фактчекинга (7 уровней)

> **ЕДИНСТВЕННЫЙ источник правды** по схеме водопада, правилам эскалации и словарю вердиктов.
> Если схема встречается где-то ещё — это устаревшая копия, ссылайся на этот файл.

```
Ур.0.5 → OpenAlex API           (мгновенная проверка DOI)
Ур.1   → researcher-web         (поиск фактов)
Ур.2   → Crawl4AI               (базовый HTTP-парсинг)
Ур.3   → Scrapling              (обход Cloudflare, бесплатно)
Ур.4   → FireCrawl              (платный резерв)
Ур.5   → Человек                (ручная верификация)
Ур.6   → Gemini DeepSearch      (опционально)
```

## Уровни и правила эскалации

| Уровень | Инструмент | Цена | Когда применять | Условие передачи наверх |
|:---:|---|---|---|---|
| 0.5 | OpenAlex API | Бесплатно (CC0, без ключа) | Всегда первым делом для URL с `doi.org` или DOI в поле `expect` — мгновенная проверка существования статьи | NOT_FOUND → Ур.1 |
| 1 | researcher-web | Бесплатно (встроен) | Базовые факты (PMID, DOI, адреса); URL без DOI; после NOT_FOUND на Ур.0.5 | — (следующий по каскаду — Ур.2) |
| 2 | Crawl4AI | Бесплатно | Базовый HTTP-парсинг любых URL (после проверки DOI) | EMPTY / Cloudflare / мало текста / TIMEOUT → Ур.3 |
| 3 | Scrapling StealthySession | Бесплатно (локальный Playwright) | Сайт с anti-bot защитой (Cloudflare Turnstile, DataDome); после неудачи Crawl4AI | Не справился (EMPTY/ERROR) → Ур.4 |
| 4 | FireCrawl | Платные кредиты (резерв) | Только если Scrapling не справился; неизвестная anti-bot защита; нужен гарантированный markdown | Заблокировано → пометка `BLOCKED` и Ур.5 |
| 5 | Человек | Ручная работа | Ручная верификация оставшихся заблокированных URL | — (конечная проверка) |
| 6 | Gemini DeepSearch | Опционально (LLM-кредиты) | Независимое подтверждение особо важных фактов | — (финальный уровень) |

**Принцип:** ~95% проверок закрываются на бесплатных уровнях (Ур.0.5–3).
FireCrawl (Ур.4) — только как резерв: **всегда пробовать Scrapling перед FireCrawl — экономия кредитов.**

## Словарь вердиктов факт-чекера

| Вердикт | Семантика |
|---|---|
| `CONFIRMED` | Факт подтверждён — есть прямая цитата и URL источника |
| `REFUTED` | Факт опровергнут |
| `UNCERTAIN` | Подтверждение не найдено. **НИКОГДА не выдумывать подтверждения** — если не нашёл, пиши `UNCERTAIN` |
| `BLOCKED` | Источник заблокирован (`ip заблокирован`, `cloudflare`, `security verification`) — помечать `BLOCKED`, а не `CONFIRMED` |

> **Ремарка:** это вердикты факт-чекера (Роль 5, см. architecture.md). Низкоуровневые
> программные статусы скриптов — `CONFIRMED` / `MISMATCH` / `ERROR` / `SKIP` — это
> статусы отдельных запусков (`STATUS:` в `workspace/{prefix}_{id}.txt`), не финальные
> вердикты по факту.
