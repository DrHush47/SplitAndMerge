# presentation-protocol.md — Протокол генерации и визуальной верификации презентаций (.pptx)

> **Назначение модуля:**
> Автономная сборка и валидация презентаций формата `.pptx` в стиле академического минимализма с подбором подлинных научных иллюстраций высокого разрешения и синхронной подготовкой сопутствующих материалов доклада (реферат по ГОСТ, текст для устного выступления).
>
> **Роли в конвейере:**
> - **Технический исполнитель (Роль 4):** сборка презентации через `python-pptx`, применение алгоритма `fit_in_box`, экспорт слайдов.
> - **Рецензент (Роль 2):** программная и визуальная проверка экспортированных слайдов (отсутствие деформаций, читаемость шрифтов, отсутствие наложений).
> - **Текстовик (Роль 3):** подготовка емких тезисов слайдов, академического реферата (`*реф.docx`) и устного текста для выступления (`*през.docx`).

---

## 1. Главные принципы и ограничения (Critical Constraints)

### 1.1 Категорический запрет на генерацию картинок кодом
* **ЗАПРЕЩЕНО:** Использовать HTML, CSS, SVG, Canvas, скрипты Playwright или скриншотеры браузера для синтетической отрисовки диаграмм, схем и иллюстраций.
* **ОБЯЗАТЕЛЬНО:** Искать и скачивать **только подлинные, реальные изображения из интернета** (музейные оцифровки, исторические анатомические атласы, научные микропрепараты, фотографии животных в естественной среде из Wikimedia Commons API, Unsplash, открытых научных архивов).
* **Разрешение:** Строго от **1080p до 4K/8K** (минимальный линейный размер от 1700px до 3840px+). Размытые превью и thumbnails запрещены.

### 1.2 Алгоритм `fit_in_box` (Нулевая деформация пропорций)
Картинки ни при каких обстоятельствах не должны растягиваться, сплющиваться или деформировать исходный Aspect Ratio. Масштабирование выполняется строго через библиотеку `Pillow` с центрированием в отведенном контейнере:

```python
from PIL import Image

def add_fitted_picture(slide, image_path, box_left, box_top, box_width, box_height):
    """
    Вставляет изображение в заданный прямоугольник (box) без искажения пропорций
    и центрирует его внутри контейнера по вертикали и горизонтали.
    """
    with Image.open(image_path) as img:
        orig_w, orig_h = img.size

    aspect_img = orig_w / orig_h
    aspect_box = box_width / box_height

    if aspect_img > aspect_box:
        # Картинка шире контейнера — масштабируем по ширине
        final_w = box_width
        final_h = box_width / aspect_img
        offset_x = 0
        offset_y = (box_height - final_h) / 2
    else:
        # Картинка выше контейнера — масштабируем по высоте
        final_h = box_height
        final_w = box_height * aspect_img
        offset_y = 0
        offset_x = (box_width - final_w) / 2

    return slide.shapes.add_picture(
        image_path,
        left=box_left + offset_x,
        top=box_top + offset_y,
        width=final_w,
        height=final_h
    )
```

### 1.3 Академический минимализм и геометрия 16:9
* **Формат слайда:** 16:9 Widescreen (`13.333 × 7.500` дюймов).
* **Палитра (светлый журнальный стиль Nature/Science):**
  * Фон слайда: мягкий холодный оттенок `RGBColor(248, 250, 252)` (Slate-50).
  * Карточка-подложка под иллюстрацию: чистый белый `RGBColor(255, 255, 255)` с тонкой рамкой 1pt `RGBColor(226, 232, 240)`.
  * Заголовки: глубокий антрацит `RGBColor(15, 23, 42)` (Slate-900).
  * Основной текст: высококонтрастный `RGBColor(51, 65, 85)` (Slate-700).
  * Рубрикаторы / бейджи: королевский синий `RGBColor(37, 99, 235)` (Royal Blue).
  * Подписи источников: приглушённый `RGBColor(100, 116, 139)` (Slate-500).
* **Иерархия шрифтов (гарнитура Segoe UI / Aptos / Arial):**
  * Заголовок титульного слайда: **35 pt** bold.
  * Подзаголовок титульного слайда: **18 pt**.
  * Заголовки контентных слайдов: **26.5 pt** bold.
  * Ключевые термины тезисов: **16.5 pt** bold.
  * Описание тезисов: **15.5 pt** regular.
  * Интервалы между тезисами: `space_after = Pt(13)` (слайд должен «дышать»).
  * Подписи к иллюстрациям: **11 pt** italic.
* **Отказ от визуального мусора:**
  * Никаких декоративных псевдо-полосок под заголовками (антипаттерн Anthropic Gold Standard).
  * Отказ от тяжелых нижних колонтитулов: полезное пространство отдаётся крупному изображению и легко читаемому тексту.

## 2. Архитектура и стек инструментов

Модуль презентаций объединяет три взаимодополняющих технологических слоя:

| Слой | Инструменты | Назначение |
|---|---|---|
| **Ядро генерации** | `python-pptx`, `Pillow` | Программная сборка `.pptx` по расчетной сетке, точное позиционирование блоков, управление типографикой и цветом. |
| **Агентные скиллы** | `.agents/skills/pptx/` (Anthropic PptxGenJS + OOXML), `skills/ppt-master/` (MBB), `skills/ppt-visual/` | Архитектурные пресеты, топологии слайдов, валидация DrawingML/XML. |
| **Визуальный Quality Gate** | `PowerPoint COM API` (`export_slides.ps1`) | Нативный фоновый экспорт слайдов в Full HD PNG (1920×1080) через установленный Microsoft PowerPoint 365 для программного аудита Рецензентом. |

## 3. Протокол сопутствующих документов (Презентация + Текст + Реферат)

В академической и клинической практике презентация не существует изолированно. Модуль формирует **триаду материалов 1 в 1**:

```
workspace/
├── [тема]_презентация.pptx      ← Итоговый файл слайдов (16:9, Ultra-HD иллюстрации)
├── [имя]през2.docx              ← Текст устного выступления с таймингом на докладчиков
└── [имя]реф2.docx               ← Академический реферат по ГОСТ (титульный лист, Введение, 4 главы, Список источников)
```

### 3.1 Требования к тексту выступления (`*през2.docx`)
* Шрифт Times New Roman 12 pt, межстрочный интервал 1.15.
* Пометки нечитаемых слайдов: `Титульный слайд (1) и конечный слайд (N) не читаются.`
* Распределение хронометража по спикерам (например: *Ёдгорова Ш. (слайды 2–5, около 4 минут)*, *Черкасов И. С. (слайды 6–8, около 4 минут)*).
* Устная академическая речь: связный нарратив, адаптация к профилю аудитории, терминологическая строгость.

### 3.2 Требования к реферату (`*реф2.docx`)
* Стандартные поля ГОСТ: левое — 30 мм (85.05 pt), правое — 15 мм (42.5 pt), верхнее и нижнее — 20 мм (56.7 pt).
* Шрифт Times New Roman 12 pt (заголовки 14 pt bold), межстрочный интервал 1.0.
* Полный титульный лист с точным числом отступов, кафедрой, авторами и годом.
* Обязательная структура:
  1. **ВВЕДЕНИЕ:** контекст проблемы, обоснование актуальности, цель и 5 конкретных задач.
  2. **ОСНОВНАЯ ЧАСТЬ:** 4 тематические главы с подробными академическими параграфами и сквозной нумерацией ссылок `[1, 2]`.
  3. **ЗАКЛЮЧЕНИЕ:** выводы и прикладное значение для клинической медицины/биологии.
  4. **СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ:** 10–12 авторитетных фундаментальных изданий по ГОСТ 7.0.5–2008.

## 4. Чек-лист валидации перед сдачей (Quality Gate)

Перед фиксацией результатов Рецензент и Технический исполнитель проверяют:

- [ ] **Реальность иллюстраций:** 0 синтетических генераций, все изображения — подлинные фото/оцифровки ≥1080p.
- [ ] **Нулевая деформация:** функция `add_fitted_picture` применила правильные `final_w` и `final_h`.
- [ ] **Отсутствие наложений:** текст не наезжает на изображение, правая карточка имеет отступ от левого текста не менее 0.8–1.0 дюйма.
- [ ] **Читаемость шрифтов:** заголовки ≥25 pt, тезисы ≥15 pt, контраст текста к фону удовлетворяет WCAG AAA.
- [ ] **Синхронность авторов:** титульный слайд, текст выступления и реферат содержат одинаковые ФИО авторов и данные группы/факультета.
- [ ] **Экспорт PNG:** выполнен нативный экспорт через PowerPoint COM без предупреждений и ошибок.
